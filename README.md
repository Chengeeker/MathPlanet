# 数学星球 MathPlanet

Android Kotlin + Jetpack Compose 儿童数学游戏。包名：`com.game.maths`；当前构建版本：**2.0.16 (67)**。

## 玩法入口

- **算数探险**：原有的加减乘除、四选一、数字填空、分步骤计算讲解。
- **小小商店**：顾客付款、店长找零、不同面额货币练习。
- **计算对决**：双人/AI、速度与正确率规则，保留原有玩法。
- **综合数学练习（新增，可选）**：独立的儿童练习区，默认「幼小衔接·大班」，不改变上述三个游戏的出题池、设置与统计。每局 8 题，有提示、正确答案和讲解。
- **花园保卫战**：改编自《植物大战僵尸》的答题塔防模式，入口分为冒险、迷你游戏、益智、生存；后三种暂显示“正在开发，敬请期待”，另保留自由战斗。冒险模式包含五章节、50 个线性解锁关卡，映射白天草坪、夜晚草坪、六行双水路泳池、雾夜泳池和带斜坡/平顶的屋顶；1-1 仅开放中间行且仅提供豌豆射手，4-5 单独使用夜晚草坪。战斗仍使用 150 秒循环，保龄球/传送带/墓碑敲击/花瓶等独立规则尚未实现。植物与敌种按阶段开放；自由战斗难度和战役进度分开保存。战场收录经典版 49 种植物、26 种僵尸及明确标注的原创高速僵尸；角色与场景均以 Compose Canvas 扁平矢量方式绘制。
- 阳光经济：普通阳光答题奖励 25；每次普通阳光有 20% 概率升级为奖励 75 的大阳光，连续四次普通后的第五次保底为大阳光。大阳光需手动答题，不受自动收集影响；题目基于当前范围或计算项数交替增加一档，避免同时抬高两项。
- v2.0.16 调整全战役击杀后的补怪间隔和僵尸威胁预算，使轻甲/特殊敌人不再和普通僵尸按同一档频繁补入；加入陆地行小推车清场动画，并在触发后短暂阻止该行出怪；植物卡费用显示阳光图标。
- v2.0.15 修正大阳光范围挑战必须实际用到原范围以外的数字、冷却遮罩圆角和大阳光静态光晕；樱桃炸弹按相邻整格覆盖 3×3；普通僵尸啃咬拆为更细的多次扣血。

历史修复记录见 [CHANGELOG.md](CHANGELOG.md)。

### 综合数学练习

支持按学习阶段选题，**默认幼小衔接**；需家长主动切换到更高年级。

| 学习阶段 | 内容 |
| --- | --- |
| 幼小衔接·大班 | 10 以内生活加减、数圆点、识别形状、简单数列规律 |
| 一年级 | 20 以内加减、看图分组、简单比较、整点钟表 |
| 二年级 | 乘除、平均分、购物找零、半点、简单统计图 |
| 三年级 | 两步应用题、长方形周长、统计 |
| 四年级 | 长方形面积、周长及已有综合主题 |

后续五六年级知识尚未开放，避免直接让幼儿遇到不适龄内容。新题采用受约束的程序化模板、固定正确答案和解释文本，图片均由 Compose 绘制。

### 汉字拼音辅助

在 **设置 → 声音与节奏 → 汉字拼音辅助** 开启，默认关闭。开启后，在主要游戏文字界面为可转换的汉字显示上方带声调的拼音；关闭时使用原始 Material3 Text 布局。适用于 Android 10 / API 29 及更新系统提供 Han-Latin 或 Any-Latin ICU 转写的设备。低版本或不提供此转写器的设备会保持原始汉字，个别多音字可能需要进一步人工校正。

### 配音与背景音乐

经典算术保留原有离线中文音频片段、AudioTrack PCM / 系统播放切换、独立的背景音乐与音效开关；语音开始时暂时暂停背景音乐，避免在 目标设备 上同时混音导致额外延迟。综合练习的任意中文应用题支持点击「读题」，由设备上的中文 TTS 引擎朗读；TTS 引擎不可用时仍可阅读图文练习。

## 构建与测试

- 开发检查：`gradlew.bat :app:testDebugUnitTest :app:assembleRelease`（Release 使用原签名脚本，不生成独立调试安装包）。
- 原证书签名：`powershell -ExecutionPolicy Bypass -File scripts/sign-release.ps1`（需本地 `key.properties`，该文件不得上传仓库）。
- 包名和原有签名保持不变，可从旧版覆盖升级，不清除本地进度。
- 详细历史修复记录已转至 [CHANGELOG.md](CHANGELOG.md)；README 只保留当前功能及使用说明。

> 真实平板上仍需核对：打开拼音时汉字换行、文字按钮点击、不同多音字的读音，以及新应用题的 TTS 与音乐暂停效果。
