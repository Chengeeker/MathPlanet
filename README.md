# 数学星球 MathPlanet

Android Kotlin + Jetpack Compose 儿童数学游戏。包名：`com.game.maths`；当前本地构建版本：**2.0.0**。

## 玩法入口

- **算数探险**：原有的加减乘除、四选一、数字填空、分步骤计算讲解。
- **小小商店**：顾客付款、店长找零、不同面额货币练习。
- **计算对决**：双人/AI、速度与正确率规则，保留原有玩法。
- **综合数学练习（新增，可选）**：独立的儿童练习区，默认「幼小衔接·大班」，不改变上述三个游戏的出题池、设置与统计。每局 8 题，有提示、正确答案和讲解。
- **星球守护局（新增）**：原创题答塔防模式，横屏 5×9 草坪/水域战场，单位原创矢量形象、植物/敌人图鉴、明确的种植和暂停反馈。简单答题暂停；困难答题继续；噩梦答题继续且答错扣 25 星能。种子卡显示费用与实时冷却遮罩，落地星能答对获得 50 星能；每 3 道成功答题固定获得 2 次自动收集。美术和名称均为原创，不携带 EA 游戏素材。

首版为可玩的机制原型：单位目录较全，但场景条件、单位数值和平衡、少数特殊行为及逐单位验收仍待完善。界面与交互要求见[体验规格](<D:\App\开发文档\数学星球\星球守护局界面与交互规格.md>)，机制记录见[开发记录](<D:\App\开发文档\数学星球\星球守护局答题塔防可行性.md>)。

### 综合数学练习

支持按学习阶段选题，**默认幼小衔接**；需家长主动切换到更高年级。

| 学习阶段 | 内容 |
| --- | --- |
| 幼小衔接·大班 | 10 以内生活加减、数圆点、识别形状、简单数列规律 |
| 一年级 | 20 以内加减、看图分组、简单比较、整点钟表 |
| 二年级 | 乘除、平均分、购物找零、半点、简单统计图 |
| 三年级 | 两步应用题、长方形周长、统计 |
| 四年级 | 长方形面积、周长及已有综合主题 |

后续五六年级知识尚未开放，避免直接让幼儿遇到不适龄内容。新题采用受约束的程序化模板、固定正确答案和解释文本，图片均由 Compose 绘制。

### 汉字拼音辅助

在 **设置 → 声音与节奏 → 汉字拼音辅助** 开启，默认关闭。开启后，在主要游戏文字界面为可转换的汉字显示上方带声调的拼音；关闭时使用原始 Material3 Text 布局。适用于 Android 10 / API 29 及更新系统提供 Han-Latin 或 Any-Latin ICU 转写的设备。低版本或不提供此转写器的设备会保持原始汉字，个别多音字可能需要进一步人工校正。

### 配音与背景音乐

经典算术保留原有离线中文音频片段、AudioTrack PCM / 系统播放切换、独立的背景音乐与音效开关；语音开始时暂时暂停背景音乐，避免在 PA2373 上同时混音导致额外延迟。综合练习的任意中文应用题支持点击「读题」，由设备上的中文 TTS 引擎朗读；TTS 引擎不可用时仍可阅读图文练习。
